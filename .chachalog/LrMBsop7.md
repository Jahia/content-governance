Added a catalog of content rules, which a site changes as content, so that every check applies one value per rule.

Each finding shows the id of its rule. A site turns a rule off, or changes its severity or its limits, under Content folders > content-insights > jahia > rules. Some defaults changed: a GEO title now passes from 30 to 60 characters, and a GEO meta description must be 50 to 160 characters.
